## Usage

Search and play your Spotify music via the `spotify` keyword.

![Spotify Mini Player](images/player.png)

Browse **Playlists**, **Albums**, **Artists**, and **Songs**, or type to search.
**Songs** contains your Liked Songs. Use the **＋** beside the current song to
save it; a green checkmark means it’s already liked. The shuffle button toggles
shuffle, and the Spotify icon opens the desktop app.

* <kbd>↩</kbd> Browse the selection or play a song.
* <kbd>⌘</kbd><kbd>↩</kbd> Search the full Spotify catalogue.
* <kbd>Esc</kbd> Hide the player.

Configure the Hotkey for faster access. Press it again while the player is
focused to open Spotify. The player stays ready in the background while Alfred
is running.

Use the gear to open the Workflow’s Configuration. If you need to sign in again,
use the `spotify reauth` keyword, then reopen the player. Existing connections
need this once to enable saving songs.
